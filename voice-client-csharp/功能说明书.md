## 2. 功能详解

### 2.1 流水线状态圈

| 圆圈 | 标签 | 图标 | 倒计时 | 旋转方向 | 用途 |
|------|------|------|--------|----------|------|
| 第1圈 | 麦克风 | 🎤 | 90秒 | 顺时针 | 录音倒计时 |
| 第2圈 | ASR | ⚡ | 30秒 | 逆时针 | ASR 识别倒计时 |
| 第3圈 | Hermes | 🤖 | 30秒 | 顺时针 | LLM 回复倒计时 |
| 第4圈 | TTS | 🔊 | 30秒 | 顺时针 | TTS 合成倒计时 |

**状态颜色说明：**
- 🟢 绿色：延迟 < 35ms，服务状态良好
- 🟡 黄色：延迟 35-350ms，网络一般
- 🔴 红色：延迟 > 350ms，网络较差
- ⚫ 灰色：空闲状态
- ❌ 红叉：服务连接失败，点击可触发诊断

### 2.2 语音录制

**按住说话模式（默认）：**
1. 鼠标按下 🎤 按钮 → 开始录音
2. 麦克风圈开始 90 秒倒计时
3. 松开鼠标 → 停止录音 → 自动进入处理流程
4. 录音过程中按钮变红，状态显示「录音中...」

**持续监听模式：**
1. 点击「按住说话」按钮切换
2. 单击 🎤 开始录音
3. 再次单击停止并发送

### 2.3 聊天气泡

- **我的消息（用户）**：右侧紫色气泡
- **Hermes 消息（助手）**：左侧灰色气泡
- **系统消息**：居中灰色小字
- **语音消息**：带 🔊 图标的波形条，点击可播放
- 每条消息显示时间戳
- 新消息自动滚动到底部

### 2.4 打字输入
- 底部输入框打字，按 Enter 或点「发送」
- 不经过 ASR，直接进入 LLM 对话
- 同样触发 TTS 语音播放

### 2.5 服务诊断

**自动检测（启动时 + 每30秒）：**
- 自动探测 ASR(12026)、Hermes(8642)、TTS(1234) 端口
- 端口通 → 圆圈绿色；端口不通 → 红叉

**手动诊断（点击红叉圆圈）：**
1. 点击红叉圆圈
2. 后端执行 TCP 端口探测（3秒超时）
3. 结果圆圈：✅ 绿色（已恢复）或 ❌ 红色（仍故障）
4. 诊断消息显示在聊天区

## 3. 调试模式

### 3.1 操作步骤

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 点击「🔧调试」 | 进入调试模式，按钮变灰 |
| 2 | 自动通知 Hermes | 发送「调试要开始了哟，你准备好监控」 |
| 3 | 自动录音 3 秒 | 麦克风圈倒计时 |
| 4 | 生成语音气泡 | 录音显示为可点击播放的语音条 |
| 5 | 自动 ASR 识别 | ASR 圈逆时针倒计时 |
| 6 | 自动 LLM 对话 | Hermes 圈倒计时 |
| 7 | 自动 TTS 合成 | TTS 圈倒计时，播放语音 |
| 8 | 显示调试结果 | 所有结果以气泡形式展示 |
| 9 | 出现「📤 发送调试日志」按钮 | 位于聊天区下方 |

### 3.2 发送调试日志

点击「📤 发送调试日志给 Hermes」后：
1. 读取当日日志文件（最近 200 行）
2. 拼接系统信息（用户名、机器名、OS 版本、后端地址）
3. 发送给 Hermes 分析
4. Hermes 返回诊断报告和建议
5. 调试模式结束

## 4. 配置说明

### 4.1 后端地址
- 默认：`http://192.168.1.21:12054`
- 修改位置：`MainForm.cs` 第 21 行的 `BACKEND_URL` 常量

### 4.2 日志路径
- `%LOCALAPPDATA%\VoiceClient\logs\voice_yyyyMMdd.log`
- 例如：`C:\Users\oakcn\AppData\Local\VoiceClient\logs\voice_20260515.log`

## 5. 编译与运行

### 5.1 编译环境
- Visual Studio 2019+
- .NET Framework 4.7.2 SDK
- Windows 10/11 x86

### 5.2 编译步骤
1. 用 VS2019 打开 `VoiceClient.sln`
2. 选择 `Debug | x86` 配置
3. 按 F6 编译
4. 运行 `bin\Debug\VoiceClient.exe`

### 5.3 依赖
- 无第三方 NuGet 包
- 仅使用 .NET Framework 内置库
- 录音使用 Windows waveIn API（winmm.dll）

## 6. 错误处理

| 错误场景 | 用户看到 | 日志记录 |
|----------|----------|----------|
| 麦克风无法打开 | ⚠️ 录音失败: xxx | ERROR AudioRecorder |
| ASR 超时/失败 | ⚠️ ASR 识别失败: xxx | ERROR/WARN ApiClient |
| LLM 超时/失败 | ⚠️ LLM 回复失败: xxx | ERROR/WARN ApiClient |
| TTS 失败 | 自动 fallback 到 Edge TTS | WARN ApiClient |
| 后端连接失败 | 圆圈红叉，可点击诊断 | WARN ApiClient |
| 调试异常 | ⚠️ 调试异常: xxx | ERROR Logger |
