# 🎙️ Hermes 语音通话客户端 — 需求说明书

## 1. 项目概述

### 1.1 项目名称
Hermes 语音通话客户端（VoiceClient）

### 1.2 项目定位
面向 Hermes AI 助手的语音交互桌面客户端，提供「语音识别 → AI 对话 → 语音合成」的全链路实时通话能力。

### 1.3 目标用户
- 需要与 Hermes 进行语音对话的桌面用户
- 需要快速排查语音链路故障的调试人员

### 1.4 技术栈
- 语言：C# (.NET Framework 4.7.2)
- UI 框架：WinForms
- 录音：Windows waveIn API（无需第三方库）
- 协议：HTTP/REST
- 编译环境：Visual Studio 2019+

## 2. 业务需求

### 2.1 核心需求
| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| R-01 | 语音录制 | P0 | 通过麦克风录制用户语音 |
| R-02 | ASR 语音识别 | P0 | 将语音转为文字 |
| R-03 | LLM 对话 | P0 | 将文字发送给 Hermes 获取回答 |
| R-04 | TTS 语音合成 | P0 | 将回答转为语音播放 |
| R-05 | 文字输入 | P0 | 支持键盘打字输入对话 |

### 2.2 辅助需求
| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| R-06 | 流水线状态指示 | P1 | 实时显示录音→ASR→LLM→TTS各环节状态 |
| R-07 | 服务健康检测 | P1 | 自动检测各服务端口是否在线 |
| R-08 | 故障诊断 | P1 | 红叉圆圈可点击，触发端口检测 |
| R-09 | 调试模式 | P2 | 全链路自动测试，生成诊断报告 |
| R-10 | 日志记录 | P1 | 所有重要操作写入日志文件 |
| R-11 | 语音气泡回放 | P2 | 自己的录音以气泡形式显示，可点击播放 |

## 3. 功能需求

### 3.1 语音录制
- **按住说话模式**：按住按钮开始录音，松开自动停止并发送
- **持续监听模式**：单击按钮开始录音，再次单击停止
- 录音上限 90 秒，麦克风外圈倒计时
- 采样率 16kHz，16-bit，单声道 PCM

### 3.2 语音识别 (ASR)
- 将录制音频发送到后端 `/api/asr`
- 后端转发到 A3B llama.cpp (12026)
- 30 秒超时，ASR 圈逆时针倒计时
- 识别失败显示错误提示

### 3.3 AI 对话 (LLM)
- 将 ASR 结果发送到 Hermes Gateway `/api/chat`
- Hermes 转发到 DeepSeek 云端模型
- 30 秒超时，Hermes 圈倒计时
- 同步聊天记录到后端历史系统

### 3.4 语音合成 (TTS)
- 将 Hermes 回答截取前 100 字发送到 `/api/tts`
- 优先 Qwen TTS，失败自动 fallback 到 Edge TTS
- 30 秒超时，TTS 圈倒计时
- 使用 `System.Media.SoundPlayer` 播放

### 3.5 流水线状态指示
- 四个圆圈：麦克风、ASR、Hermes、TTS
- 外圈倒计时动画（顺时针/逆时针）
- 内圈颜色：绿(<35ms)、黄(35-350ms)、红(>350ms)
- 红叉故障指示，hover 高亮，点击触发诊断

### 3.6 调试模式
- 点击「🔧调试」按钮进入调试模式
- 自动通知 Hermes「调试要开始了哟，你准备好监控」
- 录制 3 秒音频 → ASR → LLM → TTS 全链测试
- 显示测试结果在聊天区
- 调试完成后显示「📤 发送调试日志给 Hermes」按钮
- 点击后读取日志文件 + 诊断信息 → 发送给 Hermes 分析

### 3.7 日志记录
- 路径：`%LOCALAPPDATA%\VoiceClient\logs\voice_yyyyMMdd.log`
- 记录：API 请求/响应、录音开始/结束、异常堆栈、状态变化
- 自动按日期分文件

## 4. 非功能需求

| 编号 | 需求 | 指标 |
|------|------|------|
| N-01 | 响应时间 | ASR < 5s, LLM < 10s, TTS < 5s |
| N-02 | 内存占用 | < 100MB |
| N-03 | 启动时间 | < 3s |
| N-04 | 日志大小 | 单文件 < 10MB, 自动轮转 |
| N-05 | 兼容性 | Windows 10/11, .NET 4.7.2+ |
| N-06 | 网络要求 | 可访问后端 bt2:12054 |

---

## 5. 数据流

```
[用户说话] → [麦克风 waveIn] → [16kHz WAV]
  → POST /api/asr → [A3B llama.cpp 识别] → 文字
  → POST /api/chat → [Hermes Gateway] → [DeepSeek API] → 回答
  → POST /api/tts → [Qwen/Edge TTS] → WAV 音频
  → [SoundPlayer 播放] → [用户听到]
```
